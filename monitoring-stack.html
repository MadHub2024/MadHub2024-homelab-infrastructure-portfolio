Case study 04

Monitoring and Observability Stack

Combining multiple tools to monitor network devices, Linux hosts, containers, endpoints, and service availability.

LibreNMSPrometheusGrafanaUptime KumacAdvisor

Objective

No single monitoring platform provides the best view of every layer. The goal was to combine infrastructure metrics, network discovery, container utilization, and user-visible service checks.

Tool responsibilities

  • LibreNMS: network devices, SNMP, discovery, and inventory.
  • Prometheus: time-series metrics and exporter collection.
  • Grafana: dashboards and visualization.
  • cAdvisor: container resource metrics.
  • Node Exporter: Linux host metrics.
  • Blackbox Exporter: endpoint probing.
  • Uptime Kuma: service-oriented uptime and availability checks.

Troubleshooting work

Monitoring implementation required Docker network validation, port checks, container log analysis, exporter configuration, and SNMP testing across VLAN boundaries.

Result

The layered design makes it possible to distinguish a host resource problem from a container issue, a network device failure, or an application endpoint outage.
